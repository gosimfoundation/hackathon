# Hub archive cover images

The archive cards use local copies of existing event visuals. They do not
depend on third-party image requests or the assembled event routes at runtime.

| Hub asset | Original source |
| --- | --- |
| `images/events/gaac.png` | User-provided GAAC application-scenarios image; displayed at its original aspect ratio without cropping |
| `images/events/factory26.jpg` | Factory release: `videos/shenzhen-hero-sz1-poster.jpg`, the homepage video poster |
| `images/events/survey26.jpg` | Survey release: `platform/media/survey-milky-way.jpg` |
| `images/events/agenticapp26.jpg` | Agentic App release: `videos/agent2app-day-v2.jpg`, the homepage daytime visual |
| `images/hackathon-hero.jpg` | Existing hub hero photograph from GOSIM Paris |
| `images/events/super-agent-2025.jpg` | [Super Agent homepage](https://mofa.ai/super-agent-hackathon/), `mofa-website/public/images/科技风壁纸.png` in [the MoFA website repository](https://github.com/mofa-org/mofa-org.github.io) |
| `images/events/code-alert-2025.jpg` | [MoFA's event recap](https://mofa.ai/blog/en/code-alert-n-super-agent/), `mofa-website/public/images/block-board.jpg` in the same repository |

The two MoFA source images were resized and JPEG-compressed for the cards.
All covers use lazy loading and a consistent 16:9 display crop. The images
include illustrations and event artwork, so their alternative text describes
the actual visual rather than presenting them as event photographs.
